   # expect: groupconfigs, namespaceconfigs

RBAC POLICIES
=============
This chart deploys the NamespaceConfig and GroupConfig policies enabled in values: the
baseline namespace tiers and the cluster GroupConfig ship enabled, the oud-group example
and the custom GroupConfig ship disabled. Once the operator is running:

   $ oc get namespaceconfigs.redhatcop.redhat.io
   $ oc get groupconfigs.redhatcop.redhat.io

The YAML under working-sessions/policies in the repository is the readable design
reference. Do not apply those copies alongside the chart: they would duplicate or contend
with the CRs the chart manages.

TROUBLESHOOTING
===============
- Stuck InstallPlan:
    $ oc describe installplans.operators.coreos.com -n {{ .Values.namespace }}
- If you installed into a namespace that already had a global OperatorGroup, set
  createOperatorGroup=false — two global OperatorGroups in one namespace conflict.
- Operator logs:
    $ oc logs -n {{ .Values.namespace }} deployment/namespace-configuration-operator-controller-manager -c manager --tail=100
